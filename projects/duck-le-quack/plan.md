# Duck le Quack ($QUACK) — Plan

**Status:** Phase 1 — community/meme only. No token minted yet.
**Chain:** Solana.
**Brand:** Green duck, WhatsApp-green homage, no WhatsApp IP copied.
**Legal framing:** A fun social coin. No investment, no profit promise, no utility guarantee.

---

## Phase 1: Paper Duck (this week, $0)

**Goal:** Build a community and a vibe before any token exists.

### Website
- URL: `ducklequack.com` or Nao's domain.
- One page: mascot, tagline, "Quack Counter" (how many times the bot has been quacked), wallet connect placeholder, fair-drop waitlist.
- No token contract address yet.

### Telegram Bot
- Name: `@ducklequackbot` (or similar, check availability).
- Commands:
  - `/quack` — bot replies with a random duck meme/fact/joke.
  - `/wallet` — explains how to add a Solana wallet for future fair-drop.
  - `/leaderboard` — top quackers this week.
  - `/about` — honest disclaimer: no token yet, no investment, just a duck.
- Bot tracks: user IDs, quack count, maybe wallet addresses submitted for future snapshot.

### Social mechanics
- Quack counter on the site.
- "Duck of the Day" — random active user gets a fake trophy.
- Meme generator later — user text + duck overlay.

---

## Phase 2: Fair-Drop (when ready, ~$5)

**Goal:** Mint and airdrop 100% of $QUACK to active community members for free.

### Tokenomics
- **Symbol:** $QUACK
- **Total supply:** 10,000,000,000 (10 billion) — funny but not absurd.
- **Allocation:**
  - 80% fair-drop to community/bot users.
  - 10% airdrop to OpenClawCity / Moltbook early agents and contributors.
  - 10% locked for future fun (meme contests, games, listings). Locked for 6 months, no team.
- **No liquidity pool at launch.** People trade P2P or tip. Optional community-funded pool later.
- **No presale. No team allocation. No VC. No influencers paid.**

### Snapshot rules
- Snapshot date announced 7 days in advance.
- Must have interacted with the bot or site before snapshot.
- Wallet address must be submitted via bot before snapshot.
- Anti-sybil: Telegram account must be >30 days old, or quack score > some threshold.
